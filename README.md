# حصالة البيت — House Budget Manager

تطبيق أندرويد عربي كامل لإدارة ميزانية البيت: أدخل راتبك، سجّل مصاريفك اليومية بنقرة واحدة، واحصل على تنبيهات ذكية قبل أن تنفد ميزانيتك — مع مزامنة تلقائية بين هاتفين عبر سيرفر سحابي مجاني.

| | |
|---|---|
| **اللغة** | Kotlin — واجهة عربية RTL بالكامل (مفروضة حتى على هواتف بإعدادات إنجليزية) |
| **الحد الأدنى** | Android 10 (API 29) فما فوق |
| **قاعدة البيانات المحلية** | Room — تخزين داخلي آمن بدون أي صلاحيات ملفات |
| **المزامنة** | سيرفر Node.js + Express جاهز للنشر المجاني على Render |
| **البناء الآلي** | GitHub Actions يبني ملف APK مع كل دفعة كود ويرفعه للتحميل |

## الوظائف

### الأساسيات
- **الميزانية الإجمالية**: إدخال الراتب بدورة شهرية (يوم الراتب قابل للضبط، مثال: 25 من كل شهر) أو أسبوعية.
- **المصاريف اليومية**: مبلغ + اسم + تصنيف (أغذية / فواتير / ترفيه / أخرى) — تُطرح فوراً من المتبقي.
- **التقارير**: رسم دائري لتوزيع التصنيفات بنسب مئوية، أعمدة صرف آخر 7 أيام، وملخص رقمي.

### الأفكار الذكية
- **تنبيه الإفلاس التدريجي**: مؤشر ملون (أخضر → أصفر → أحمر) يقارن نسبة المال المتبقي بنسبة الأيام المتبقية، ويتوقع تاريخ نفاد الميزانية بالمعدل الحالي ويحذّر قبلها.
- **القوالب السريعة**: أزرار جاهزة (خبز، حليب، كهرباء، ماء، إنترنت) لتعبئة العملية بنقرة — ويمكنك حفظ أي عملية كقالب جديد (اضغط مطولاً لحذف قالب).
- **الوضع الاقتصادي**: حدّد مبلغ ادخار مستهدف، وسيعاد حساب "المسموح صرفه يومياً" تلقائياً بعد خصم الهدف.

### المزامنة بين هاتفين
آلية "الأحدث يفوز" (Last-Write-Wins) حسب طابع `updatedAt` الزمني لكل سجل:
1. الهاتفان يستخدمان نفس رابط السيرفر ونفس رمز الربط (6 محارف).
2. أي إضافة مصروف / حذف / تعديل ميزانية تُرفع للسيرفر فوراً.
3. **مزامنة تلقائية كل دقيقة واحدة**: ما دام التطبيق مفتوحاً يسحب ويرفع الحالة الموحدة تلقائياً كل 60 ثانية دون أي تدخل.
4. مزامنة يدوية إضافية بزر "مزامنة الآن" في الإعدادات (تعرض نتيجة العملية).
5. الحذف ناعم (tombstone) حتى ينتقل إلى الهاتف الآخر ولا يعود بعد مزامنته.

## الخطوة 1: رفع المشروع إلى GitHub

1. أنشئ مستودعاً جديداً على [github.com/new](https://github.com/new) (عام أو خاص — Actions يعمل على الاثنين).
2. ارفع محتويات هذا المجلد كاملة (مع المجلد المخفي `.github`):

```bash
cd house-budget
git init
git add .
git commit -m "حصالة البيت: الإصدار الأول"
git branch -M main
git remote add origin https://github.com/اسمك/house-budget.git
git push -u origin main
```

3. بعد الدفعة الأولى: افتح تبويب **Actions** في المستودع — ستجد مسار "بناء تطبيق حصالة البيت" يعمل تلقائياً.
4. بعد اكتمال البناء (5–8 دقائق أول مرة): من صفحة المسار → **Artifacts** → حمّل `حصالة-البيت-APK-debug` أو `حصالة-البيت-APK-release`.
5. فك ضغط ملف الـ Artifact ثم انقل الـ APK إلى هاتفك وثبّته (فعّل "التثبيت من مصادر غير معروفة").

> يمكنك أيضاً تشغيل البناء يدوياً في أي وقت: تبويب Actions → المسار → **Run workflow**.

## الخطوة 2: نشر سيرفر المزامنة على Render

**الطريقة الأسرع (Blueprint):**
1. أنشئ حساباً مجانياً على [render.com](https://render.com).
2. New + → **Blueprint** → اختر مستودع المشروع → Render يقرأ `render.yaml` وينشئ السيرفر تلقائياً.
3. بعد دقيقة ستحصل على رابط مثل: `https://house-budget-sync.onrender.com`.

**الطريقة اليدوية (بديلة):**
1. New + → **Web Service** → اختر المستودع.
2. الإعدادات: `Root Directory: server` — `Build: npm install` — `Start: npm start` — `Runtime: Node`.

> ملاحظة عن الخطة المجانية: **نبض البقاء مفعّل تلقائياً** — السيرفر يطلب نفسه كل دقيقة فلا ينام مهما طال الخمول. وإن حدث نوم لسبب خارجي (انقطاع نادر على Render) فأول طلب يوقظه خلال ~30 ثانية. بيانات JSON المؤقتة تُمسح عند إعادة النشر فقط — لكن القاعدة الحقيقية تبقى محفوظة في هاتفيك وتُعاد مزامنتها تلقائياً عند أول اتصال.

## الخطوة 3: ربط الهاتفين

1. على الهاتف الأول: الإعدادات → **رابط سيرفر Render** → زر **توليد رمز جديد** → **فحص الاتصال** (يجب أن ينجح) → **مزامنة الآن**.
2. على الهاتف الثاني: نفس الرابط بالضبط + **نفس الرمز** → مزامنة الآن.
3. من الآن: كل مصروف تضيفه على هاتف يظهر على الآخر تلقائياً خلال دقيقة واحدة كحد أقصى (أو فوراً بمزامنة يدوية).

## نقاط اتصال السيرفر (API)

| الطريقة | المسار | الوظيفة |
|---------|--------|---------|
| GET | `/health` | فحص صحة السيرفر + حالة نبض البقاء (uptimeSec وheartbeat) |
| GET | `/api/:code/ping` | التحقق من صحة رمز الربط |
| POST | `/api/:code/sync` | رفع بيانات الهاتف + استقبال الحالة الموحدة |
| GET | `/api/:code/state` | سحب الحالة الموحدة فقط |
| DELETE | `/api/:code` | إعادة ضبط بيانات منزل بالكامل |

## استكشاف الأخطاء

| المشكلة | الحل |
|---------|------|
| فشل بناء Actions | تأكد أنك رفعت مجلد `gradle/wrapper` كاملاً (يشمل ملف jar) |
| "فشل الاتصال" في المزامنة | نبض البقاء يمنع نوم السيرفر أصلاً؛ إن حدث نوم لسبب خارجي فأول طلب يوقظه خلال 30 ثانية — أعد "فحص الاتصال" |
| بيانات اختفت بعد إعادة نشر Render | طبيعي بالخطة المجانية — افتح التطبيق على أي هاتف واضغط مزامنة |
| الهاتفان لا يتبادلان | تأكد من تطابق الرابط والرمز **حرفياً** في كليهما |
